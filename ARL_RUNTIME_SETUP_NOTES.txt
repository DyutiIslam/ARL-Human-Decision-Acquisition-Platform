ARL V13.2 MANAGED RUNTIME SETUP
===============================

1_SETUP_THIS_COMPUTER.bat now prepares ARL's own Python runtime.

On a new Windows computer it will:
- verify the ARL application files;
- download Python 3.11.9 from the official python.org distribution;
- install that Python runtime inside ARL_Runtime\Python311 (not system-wide);
- create ARL_System\.venv;
- install the exact packages listed in ARL_System\requirements.txt;
- run an import/self-test for the ARL runtime;
- create the Data folder if needed;
- write ARL_Runtime\SETUP_COMPLETE.txt after a successful setup.

The RA does not need to install Python, use pip, or activate a virtual environment manually.

FIRST-TIME REQUIREMENT
Internet access is required because Python and the Python packages are downloaded during setup.
The setup is designed as a per-user/local ARL installation and should not require a system-wide Python installation.

NOT INCLUDED
This setup intentionally does not install or configure:
- Consensys Pro
- EMOTIV PRO
- LabRecorder
- Bluetooth, Shimmer, EMOTIV, camera, microphone, or other vendor drivers

After successful setup, use 2_START_ARL.bat for normal ARL sessions.
