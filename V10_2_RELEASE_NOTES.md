# ARL v10.2 — One-Click XDF Converter Utility

Purpose: allow the moderator/researcher to convert LabRecorder `.xdf` files to CSV after every test session without using the terminal.

## Added

- `app/xdf_to_csv_gui.py`
  - Tkinter GUI for selecting an input `.xdf` file.
  - Exports each LSL stream to a separate CSV.
  - Generates `stream_summary.csv`.
  - Generates `stream_report.json`.
  - Handles marker streams and numeric streams.

- `Run_XDF_Converter.bat`
  - Double-click launcher for Windows.

## Updated

- `requirements.txt`
  - Added `pyxdf` and `pandas`.

## Usage

1. Double-click `Run_XDF_Converter.bat`.
2. Browse to the `.xdf` file generated by LabRecorder.
3. Choose or accept the output folder.
4. Click **Convert XDF to CSV**.
5. Check the generated stream CSV files and `stream_summary.csv`.

## Important

Select the actual `.xdf` file, not the folder containing it.
