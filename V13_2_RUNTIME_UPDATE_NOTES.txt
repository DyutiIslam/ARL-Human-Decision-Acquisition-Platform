ARL V13.2 - Automatic Runtime Compatibility Check

Normal use:
  Double-click 2_START_ARL.bat.

At startup ARL now checks:
  1. The isolated ARL virtual environment exists.
  2. The dependency manifest (ARL_System\requirements.txt) matches the runtime prepared for this computer.
  3. Core ARL Python modules can still be imported.

If all checks pass, ARL starts immediately.
If the runtime is missing, damaged, or the requirements changed, 2_START_ARL.bat automatically launches 1_SETUP_THIS_COMPUTER.bat to repair/update it.

Python 3.11 detection behavior is unchanged:
  - Existing compatible Python 3.11 is reused.
  - Python is installed only when compatible Python 3.11 is absent.

This means routine ARL code/UI changes that do not change requirements.txt do not trigger package reinstallation.
