# ARL Human Decision Acquisition Platform

This repository contains the stable version of the ARL Human Decision Acquisition Platform developed for multi-participant human decision-making research.

## Current Stable Version

**ARL V13.1 — LOCKED Observer / LSL / Lightweight Clients**

This version is the current stable baseline for the project.

## Project Purpose

The platform supports synchronized multi-participant behavioral and physiological data acquisition during human decision-making experiments.

The system is designed to integrate experimental events with multimodal data sources, including:

- EEG
- ECG
- EMG
- GSR
- Audio
- Video
- Behavioral responses
- Experimental event markers

Lab Streaming Layer (LSL) and LabRecorder are used for synchronized physiological and experimental event recording.

## Repository Organization

The `main` branch contains the current stable ARL version.

Older development, testing, participant-station, media, and RA-operator versions are retained in separate Git branches for development history and testing purposes.

## Important

The stable system should not be modified directly during data collection.

New features and experimental changes should be developed and tested in a separate branch before being incorporated into the stable version.
